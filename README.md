# school-games
use the branches to go through the games

## run it locally
requires node (installed). no dependencies to install.

```bash
npm start
```

then open <http://localhost:8787/?gameId=YOUR_GAME_ID&name=you> in a browser.

- default file is `blooket.js`; run another game or a TypeScript file with `node run.js some-game.ts`
- change the port with `PORT=3000 npm start`
